# 🗳️ Decentralized Voting System

## Project Overview
Blockchain-based voting system with tamper-proof records, double-voting prevention, and weighted voting.

## Features
- ✅ Double voting prevention
- ✅ Time-locked voting windows
- ✅ Weighted voting (vote power)
- ✅ Auto winner calculation
- ✅ Admin access control

## Tech Stack
- Solidity 0.8.19
- Hardhat
- Ethers.js
- MetaMask

## Setup Instructions

```bash
npm install
npx hardhat compile
npx hardhat test
npx hardhat run deploy.js
